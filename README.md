# Bài 1: Tìm kiếm tài liệu học tập chính thống bằng Google
### 1. Câu truy vấn Google
"Nhập môn Công nghệ Thông tin" filetype:pdf site:ptit.edu.vn -scribd -123doc


### 2. Giải thích các toán tử

| Toán tử | Tác dụng |
|---|---|
| `"..."` | Tìm chính xác cụm từ trong dấu ngoặc kép. |
| `filetype:pdf` | Chỉ tìm các tệp PDF. |
| `site:ptit.edu.vn` | Chỉ tìm tài liệu trên website PTIT. |
| `-scribd` | Loại bỏ kết quả từ Scribd. |
| `-123doc` | Loại bỏ kết quả từ 123doc. |

### 3. Tại sao dùng filetype:pdf?
Giúp Google lọc trực tiếp các tài liệu PDF thay vì hiển thị nhiều trang web quảng cáo, bài viết không liên quan hoặc trang yêu cầu trả phí. Nhờ đó, tiết kiệm thời gian tìm kiếm và dễ tìm được tài liệu cần thiết hơn.
